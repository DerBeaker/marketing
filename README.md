# MMSE Software – Social Media

Bilder, Videos, Werkzeuge und Redaktionsplan für Instagram **@mmse.software.moldan** (Schachtblick, AbscheiderBlick, Abscheider 3D, SpülBlick). Metricool holt die Medien über `raw.githubusercontent.com`, deshalb ist das Repo öffentlich.

- Regeln für Sitzungen: `CLAUDE.md`
- Plan: `REDAKTIONSPLAN.md`
- Werkzeuge: `werkzeuge/` (Reels mit Sprecher: `node werkzeuge/make-reel.mjs <name>`)
- Fremdfotos nur mit freier Lizenz, Nachweis in `material/fotos/LIZENZEN.md`
